# 投稿メモ（pixiv投稿管理）

pixivに投稿したイラストの **タイトル・解説コメント・URL** を保存し、キャラクター名／シチュエーションで検索できるスマホ向けWebアプリ（PWA）です。

## 主な機能
- **新規投稿**：キャラクター名（カップリングは `＆` 区切り）・シチュエーション・解説を入力すると、
  - タイトル（例：`甘織れな子＆琴紗月 攻め 4`）を自動作成
  - 同じシリーズの **過去リンクすべて** を解説の下に付けたキャプションを自動作成（例：`さつれな1 https://www.pixiv.net/artworks/…`）
  - 番号は自動で「シリーズの最大番号＋1」
  - それぞれワンタップでコピー
- **投稿後**：pixivのURLを貼り付けて保存（`https://…/artworks/ID`、`illust/ID`、IDのみ のどれでも可）
- **検索**（どれも新しい順）
  - キャラクター名のみ / シチュエーションのみ
  - キャラクター名 ＋ シチュエーション（両方に一致）
  - カップリングは片方の名前でもヒット。部分一致、全角半角・ひらがなカタカナの違いは無視
- **シリーズ画面**：略称の設定、リンク一覧のコピー、過去投稿のまとめて登録
- **設定**：URL形式（フルURL / `illust/ID`）、1作目にも「1」を付けるか、JSONでバックアップの書き出し・読み込み

データは端末のブラウザ内（localStorage）だけに保存されます。定期的にバックアップを書き出してください。

## 開発
```
npm install
npm run dev     # 開発サーバー
npm test        # テスト
npm run build   # dist/ にビルド
```

## 公開（GitHub Pages）
`main` ブランチに push すると `.github/workflows/deploy.yml` で自動公開されます。
初回のみ GitHub のリポジトリ設定 → Pages → Source を「GitHub Actions」にしてください。
公開後、iPhoneのSafariで開き「共有 → ホーム画面に追加」するとアプリとして使えます。
